# Car Dealership Inventory System

A full-stack inventory system for a car dealership, built test-first as a TDD kata. Users register, browse, search and buy vehicles; admins manage stock. Proactive inventory features: low-stock alerts, a stock-out forecast and back-in-stock notifications.

> Work in progress. Setup, screenshots, test report and the "My AI Usage" section are filled in as the build progresses.
